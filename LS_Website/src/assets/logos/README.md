# Company Logos

This folder contains company logos for the carousel on the homepage.

## Instructions

1. Add your logo images to this folder (PNG, SVG, or JPG formats work best)
2. Name them descriptively (e.g., `microsoft-logo.png`, `meta-logo.svg`)
3. Update the `logos` array in `/src/app/components/Hero.tsx` to reference your images

## Recommended Specifications

- Format: PNG or SVG (SVG preferred for scalability)
- Background: Transparent or white
- Dimensions: Any size (they will be automatically scaled to fit)
- File naming: Use lowercase with hyphens (e.g., `company-name-logo.png`)
